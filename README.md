# UNIX Shell Emulator

Эмулятор командной строки UNIX-подобной ОС, написанный на Python. Проект реализует базовый функционал оболочки (shell), включая работу с виртуальной файловой системой (VFS), интерактивный режим (REPL) и поддержку выполнения стартовых скриптов.

## Особенности проекта

*   **Виртуальная файловая система (VFS):** Строится на базе ZIP-архива. Все операции навигации, чтения и модификации (например, удаление папок) происходят строго в оперативной памяти без изменения исходного архива на жестком диске.
*   **Интерактивный режим (REPL):** Реализовано динамическое приглашение ко вводу в формате `username@hostname:pwd>`. Поддерживается корректный парсинг аргументов в одинарных и двойных кавычках.
*   **Скриптинг:** Поддержка выполнения команд из текстового файла. Эмулятор построчно читает файл, игнорирует комментарии (строки, начинающиеся с `#`), выводит команду на экран и выполняет её, имитируя живой диалог с пользователем.
*   **Отсутствие внешних зависимостей:** Проект написан исключительно с использованием стандартной библиотеки Python 3 (`zipfile`, `posixpath`, `datetime`, `unittest` и др.).

## Требования

*   Python 3.10 или выше.
*   Bash-совместимая оболочка (для запуска `run.sh` и `test.sh`).

## Запуск

Проект запускается через стартовый скрипт `run.sh`, который автоматически настраивает пути поиска модулей (`PYTHONPATH`).

### Аргументы командной строки:

*   `--vfs` (или `-v`): Путь к ZIP-архиву, выступающему в роли виртуальной файловой системы.
*   `--script` (или `-sc`): Путь к текстовому файлу со скриптом команд.

**Примеры запуска:**

1.  **Интерактивный режим (REPL) с подключенной VFS:**
    ```bash
    ./run.sh -v vfs.zip
    ```

2.  **Выполнение скрипта в тестовой ФС:**
    ```bash
    ./run.sh --vfs vfs_final.zip --script script_final.txt
    ```

## Поддерживаемые команды

| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `ls` | Выводит список файлов и папок в текущей директории. | `ls` |
| `cd` | Изменяет текущую директорию. Поддерживает абсолютные и относительные пути. | `cd docs/deep` или `cd /` |
| `date` | Выводит текущую дату и время (с учетом часового пояса). | `date` |
| `tail` | Выводит последние 10 строк указанного текстового файла из архива. | `tail report.txt` |
| `rmdir` | Удаляет пустую директорию (изменения применяются только в памяти). Ошибка, если папка содержит файлы/папки. | `rmdir empty_folder` |
| `exit` | Завершает работу эмулятора. | `exit` |

## Структура проекта

*   `src/emulator.py` — Главный модуль эмулятора (точка входа, парсер команд, REPL, чтение скриптов).
*   `src/vfs.py` — Ядро виртуальной файловой системы (парсинг ZIP, навигация, чтение, in-memory модификации).
*   `tests/` — Директория с unit-тестами.
*   `run.sh` — Скрипт для удобного запуска эмулятора.
*   `test.sh` — Скрипт для запуска всех автотестов.
*   `*.zip` — Набор тестовых виртуальных файловых систем разной сложности.
*   `script_*.txt` — Набор тестовых сценариев для автоматической проверки функционала.

## Тестирование

Проект покрыт unit-тестами, проверяющими логику парсера, работу UI (команд) и надежность VFS (включая временное создание архивов в памяти для тестов).

Для запуска полного цикла тестов выполните:
```bash
./test.sh
```
